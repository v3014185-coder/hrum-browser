# 🐹 Hrum Browser

Легкий и настраиваемый браузер с открытым исходным кодом на базе Electron. Поддерживает вкладки, смену тем и имеет милого хомяка на иконке.

## ✨ Возможности

- 📑 **Вкладки** — открывайте сколько угодно страниц.
- 🎨 **3 темы** — Тёмная, Светлая и Хомячья.
- 🔍 **Своя поисковая система** — Hrum Search (DuckDuckGo, Google или Яндекс на выбор).
- ⚙️ **Настройки** — выбор поисковика и стартовой страницы.
- 🌙 **Тёмная тема для сайтов** — автоматическое переключение на сайтах, которые это поддерживают.

## 🚀 Установка

1. Перейдите в раздел [Releases](https://github.com/v3014185-coder/hrum-browser/releases).
2. Скачайте последний файл `Hrum Setup ... .exe`.
3. Запустите установщик и следуйте инструкциям.

## 🛠️ Запуск из исходников

```bash
git clone https://github.com/v3014185-coder/hrum-browser.git
cd hrum-browser
